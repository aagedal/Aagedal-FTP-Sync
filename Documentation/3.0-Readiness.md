Status: IMPLEMENTING — routine version 3 launch is now streamlined: fresh installs
create an empty store silently, ordinary 2.9 installations receive one explicit upgrade
action, healthy committed stores reopen automatically, and technical source selection is
reserved for ambiguous/recovery inventories. Shared per-image template preparation is integrated into
preview, transfer and conditional local reprocessing. Explicit variable editors,
linked-calendar activation admission, an admitted AuraFace inference-runtime
foundation, injected recognition transfer/reprocessing paths and M5 durable processing receipts are
implemented; receipt-driven stale/incomplete reprocessing and output-edit preservation
are now selectable in the programming UI, with a no-write preflight and an explicit,
path-bound action for reviewed edit conflicts. Version 3 startup can now locally admit
and bind a strictly configured immutable face context into preview, transfer and
reprocessing before either app writer is published, and later committed opens restore
only admitted jobs configured to start on launch. People Library settings now expose

requires durable prior source evidence. Native empty-store and isolated populated-store

and interrupted-prepared recovery variants also pass. The nested-sheet accessibility
recursion is corrected, and the complete signed UI suite now passes 18 of 18 tests on

candidate readiness remain incomplete.
