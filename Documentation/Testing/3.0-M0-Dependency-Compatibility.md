## Exact dependencies and decision

FTP Sync pins SwiftMediaMetadata 2.0.0 at
`94c34f1a2562a8679694eed8ea7113e524cbd2e4`. The adjacent SwiftExif checkout is clean
at 3.0.0, `c2d77c2dcefcb997623e52beca57bc61ce302cb9`. Photo Agent's inspected
package resolution uses that exact 3.0.0 revision; its source revision and face
provenance are in [the face audit](3.0-M0-Face-Compatibility.md).

**Keep FTP Sync at 2.0.0 for the initial implementation.** Git comparison shows the
Geolocation sources unchanged between 2.0.0 and 3.0.0, and required 3.0 feature APIs
already exist in 2.0.0: offline ReverseGeocoder with distance and country localization;
XMP City/Country and `personInImage`; IPTC City/Country; JPEG and sidecar writers.
The probes below confirm those selected operations. Version 3.0.0 changes 26 metadata
implementation files (4,305 insertions, 1,748 deletions), including transaction and
semantic APIs. Adopt such an upgrade only if a later demonstrated need and the full
round-trip/regression matrix justify it. This does not claim feature equivalence or
complete format validation for either version.

Source provenance: SwiftMediaMetadata's repository is GPL-3.0. Retain its bundled
GeoNames dataset attribution when distributing app resources. No library source was
copied or modified; the standalone probe resolves the existing exact package pin.

## Adapter boundaries verified in the SDK

`MapKit.framework/Headers/MKReverseGeocodingRequest.h` declares macOS 26.0. The
probe availability-gates it. `CoreLocation.framework/Headers/CLGeocoder.h` declares
the locale-aware reverse lookup from macOS 10.13 and deprecates it at 26.0, so it
is the selected candidate for 14/15. Both expose cancellation. Apple's official
[MapKit API](https://developer.apple.com/documentation/mapkit/mkreversegeocodingrequest)
and [Core Location API](https://developer.apple.com/documentation/corelocation/clgeocoder)
were consulted; the installed SDK supplied directly inspectable availability evidence.

## Open M0/M2 gates

- Run the built probe and app on macOS 14; the only current host is macOS 27 beta.
- Validate supported embedded formats/RAW families and independent external readers.
- Implement the bounded shared queues, effective GPS-pair precedence, immutable context,
  cache/coalescing, cancellation/deadlines and stage outcomes in the actual app.
- Validate geographic edge cases and a fixed maximum-distance policy; provisionally
  retain the pinned library's 50 km limit, exposing no unsupported exact-address claim.
- Verify geocoder/data/version identity in cache/provenance and explicit locale capture.
  The library's localizedCountry helper falls back to English; production must report
  unavailable requested locale explicitly if that fallback would be misleading.
- Measure full app burst memory/throughput and cancellation separately from this probe.

M0's dependency/runtime checkbox remains incomplete until supported-OS execution and
required format evidence are present. These successful probes justify continuing the
independent implementation; they do not justify a ready-for-user-testing notification.
